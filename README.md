# 心灵家园 · Island（开源客户端）

一个以 React、R3F 和 Three.js 为基础的个人岛屿世界客户端：三维主岛与各处小天地、植被生成、动物居民、种植与摆放、昼夜四季与声景、本地草稿。

本仓库只包含**客户端和共享规则**。账号、云存档、内容平台、管理台与云端服务由官方后端提供，不在此仓库中。

| 目录 | 职责 |
|---|---|
| `apps/web` | React 界面、R3F 场景、音频、本地草稿与同步客户端 |
| `packages/contracts` | 客户端与服务端共用的接口协议和 Zod 运行时校验 |
| `packages/world-core` | 确定性生成、地形采样、摆放规则、成长与行走，不依赖 WebGL |
| `packages/physics-core` | Rapier 固定步进、角色、房间、场景模板、建造与物品交互规则 |
| `scripts/prepare-assets.mjs` | 下载狐狸 GLB、生成原创环境声与资源清单 |

`contracts` 与 `world-core` 是公开协议和规则：客户端用它们预检，服务端会用同样的规则再次校验。任何权限、权益和摆放结果都以服务端为准。

## 本地运行

需要 Node.js 22.12+ 与 pnpm 10。

```bash
pnpm install
pnpm assets:prepare
pnpm dev
```

打开 **http://localhost:5178/island**。开发服务器把 `/api` 代理到 `127.0.0.1:3001`；正式家园入口需要兼容后端确认运行能力，读取失败时显示重试。没有后端可直接访问 **http://localhost:5178/physics** 体验不保存的本地物理游乐场，账号、云存档、参观及在线房间不可用。

植被预览：`http://localhost:5178/vegetation.html`。

## 验证

```bash
pnpm typecheck
```

## 内容与扩展

主岛「工坊」支持组合方块、球体和圆柱，调整部件、撤销和恢复本机草稿。可从桌子、椅子、灯模板开始；支持按部件碰撞、跳上顶面、设置一个座面和一个光源，以及夜晚预览。新物理房间按部件形状生成碰撞；作品和场景实例分别保存。

接入支持造物协议的后端后，可按账号保存设计的不可变版本并重复摆进家园。设计和场景实例分别编号，旧摆件保持原来的版本。每件最多 24 个部件、6 × 6 × 6 空间，每岛最多 16 件造物，其中发光造物最多四件。新物理入口需要后端物理能力；权限和所有权仍由后端校验。

实际开放范围以后端能力与官方发布记录为准。外部模型导入、公开分享、上传审核与售卖尚未实现；造物只保存有界数据，不加载用户提供的 JS/React 代码。

## Rapier 物理体系

本分支提供以下新物理体系，实际开放范围由后端决定。`/physics` 是不保存的本地游乐场；在线入口需要后端开启物理能力。开启后，`/island`、十二个内置子场景、`/worlds` 和参观地址使用新账号家园；`/physics/online` 可直接管理物理世界。各场景独立保存布局、物理状态与编辑占用，离开前等待服务端保存确认，失败保留原场景。

新协议采用 `schemaVersion: 4`，作品定义、不可变版本与场景实例分别编号。服务器负责在线模拟、权限与权益、检查点和重连，浏览器预测角色并插值其他物件。基础方块、购买家具和组合创作共用物体定义；可搬物品支持受限推动、拾取、放下和轻抛。正文装置、座面、光源、开关/压力板/门及连接可保存；场景包验证模板、定义引用和持有权益，不复制购买权益。建造方块按区块合并碰撞，点光源最多四个。

主岛、家园小院、草地、森林、池塘、实验室、沙滩、星光秘境、书屋、花园、种植园、听风山与恐龙公园已接入共享物理地形与实体设施，另有物理游乐场和建造庭院。花园与种植园支持橡树/雏菊三阶段手动生长。书屋可进入阅读与学习并返回原世界；独立书籍和 AI 创作页使用轻量账号会话，不常驻三维房间。账号形象、背包、成长星星与帽饰兑换已经接入；星星和购买家具的 Credit 分开。

十三个内置场景支持采集：小物件在实际地形上生成并避开实体设施，走近后由服务端核验站立、距离和遮挡，成功才记入账号背包。每个账号、场景和位置冷却三分钟，跨设备与重复请求不能额外领取；库存满额不消耗机会。点选物件或背包收集格可打开图鉴，按当前场景权限读取岛主安装的内容，保留介绍、配图和朗读，打开时暂停角色操作。图鉴遵循后端的独立功能开关。

外围探索 `/dinosaur/explore` 使用同一 Rapier 胶囊、区块装卸与物理原点切换，手记按新世界保存。账号安装的 `/place/:sceneId` 使用共享实体几何漫游并返回来源家园。两者当前都是个人探索，没有多人房间或自由建造；均支持采集与按账号去重、冷却，发布场景另有图鉴。接触在本地物理验证，服务端验证目录、权限和回执。

具名居民与狐狸跟随、脚本问候及深聊、玩家快捷短语、天气预览、拾取提示音与小狼兑换已接入。连续发言会立即替换同一玩家的上一条气泡。仍在进行：季节视觉、许愿星灯、发布场景动物活动、完整组合负载与真机验证、旧代码清理。水面、星空和部分动物仍为视觉表现；没有真实流体、任意用户脚本、自动离线生态或无限可破坏地形。新世界不导入旧世界格式。
