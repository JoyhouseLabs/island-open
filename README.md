# 心灵家园 · Island（开源客户端）

一个以 React、R3F 和 Three.js 为基础的个人岛屿世界客户端：三维主岛与各处小天地、植被生成、动物居民、种植与摆放、昼夜四季与声景、本地草稿。

本仓库只包含**客户端和共享规则**。账号、云存档、内容平台、管理台与云端服务由官方后端提供，不在此仓库中。

| 目录 | 职责 |
|---|---|
| `apps/web` | React 界面、R3F 场景、音频、本地草稿与同步客户端 |
| `packages/contracts` | 客户端与服务端共用的接口协议和 Zod 运行时校验 |
| `packages/world-core` | 确定性生成、地形采样、摆放规则、成长与行走，不依赖 WebGL |
| `packages/physics-core` | Rapier 固定步进、角色、房间、场景模板、建造与物品交互规则 |
| `scripts/prepare-assets.mjs` | 下载狐狸 GLB、生成原创环境声与资源清单 |

`contracts` 与 `world-core` 是公开协议和规则：客户端用它们预检，服务端会用同样的规则再次校验。任何权限、权益和摆放结果都以服务端为准。

## 本地运行

需要 Node.js 22.12+ 与 pnpm 10。

```bash
pnpm install
pnpm assets:prepare
pnpm dev
```

打开 **http://localhost:5178/island**。开发服务器把 `/api` 代理到 `127.0.0.1:3001`；没有后端时以游客身份运行，修改保存在浏览器 IndexedDB 草稿中，登录、云存档、参观与在线功能不可用。

植被预览：`http://localhost:5178/vegetation.html`。

## 验证

## 内容与扩展

主岛「工坊」支持组合方块、球体和圆柱，调整部件、撤销和恢复本机草稿。可从桌子、椅子、灯模板开始；支持按部件碰撞、跳上顶面、设置一个座面和一个光源，以及夜晚预览。球体和圆柱使用保守包围盒碰撞，做桌面推荐方块。

接入支持造物协议的后端后，可按账号保存设计的不可变版本并重复摆进家园。设计和场景实例分别编号，旧摆件保持原来的版本。每件最多 24 个部件、6 × 6 × 6 空间，每岛最多 16 件造物，其中发光造物最多四件。新交互写入需要 `creationInteractionsV1` 能力声明；权限和所有权仍由后端校验。

这部分为开发功能，不代表官方生产站已经发布。外部模型导入、公开分享、上传审核与售卖尚未实现；造物只保存有界数据，不加载用户提供的 JS/React 代码。

## Rapier 开发入口

`/physics` 是不保存的本地物理游乐场。`/physics/online` 需要支持新协议并开启能力的后端，使用服务端权威模拟、检查点、预测与插值；可布置基础方块、购买家具和不可变版本的自制作品，使用正文装置、灯光与座面，并导入导出当前场景包。

在线世界包含带版本的「物理游乐场」与独立「建造庭院」。岛主首次进入时开辟庭院，各场景独立保存布局、物理状态和编辑租约，共用账号物品库存与世界分享权限。通过场景按钮离开前等待保存确认；编辑或操作尚未结束、保存失败或结果未知时不切换。参观链接包含场景位置，访客只能进入岛主已经开辟的场景。

新协议采用 `schemaVersion: 4`，场景必须引用准确的模板编号和版本；地面、升降台等基础设施由模板确定，作品实例另有稳定 UUID。此功能尚未代表官方生产站发布，现有主岛和子场景仍待迁移。在线布置现可添加开关、压力板和升降门，在「机关连接」中控制门或官方/购买/自制灯；多个输入按任意开启触发。开关状态随检查点保存，压力板重新检测，门遇到阻挡停止，收起物品会删除相关连接。当前只提供上述受控组件与端口，未开放任意脚本或反馈回路。

## 官方 Web 与统一登录

官方入口为 https://app.joyhouse.chat ，授权网关为 https://auth.joyhouse.chat 。生产后端启用统一授权后，界面提供「微信扫码登录」与「微信内授权登录」，完成授权后返回应用。客户端只接收 Island 会话，中央授权码交换和账号身份映射均由服务器处理。

M6 地形基础已接入建造庭院 v2：共享有界网格采样和三角形用于绘制、服务端碰撞和客户端预测，可表达坡面及空洞；摆放、坐站和升降门接触使用相同表面。地形属于模板，编辑及世界包导入不能改写。主岛及其他主题子场景尚未完成迁移，不能将庭院验证视作全场景验收。

外围探索 `/dinosaur/explore` 的本地开发版已使用 `PhysicsRegionWorld`：相同固定步长和胶囊控制器，按区块创建/卸载共享地形与静态部件，物理与画面共同移动原点；支持奔跑、跳跃及原有探索手记。移除了该场景的旧高度抬升/圆形避让运行代码。外围仍为单人探索，不提供新在线房间、联机或建造；主岛与其他主题场景的完整迁移仍在进行。
